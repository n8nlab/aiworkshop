Radiš sa AI agentom

Ne pišeš kod ručno. Opisuješ agentu šta želiš, on menja fajl, ti proveravaš rezultat i tražiš ispravke.

🌿

Učiš Git tok rada

Branch, commit, push i pull request — isti tok rada koji koriste profesionalni timovi svaki dan.

🌍

Objavljuješ uživo

Kad se promena spoji, sajt se automatski objavljuje. Tvoja stranica je javna i možeš da je podeliš.

⚠️

Tri pravila pre nego što kreneš

1. Menjaj samo svoj fajl ljudi/tvoje-ime.html. Ako ti trebaju slike, stavi ih u ljudi/slike/tvoje-ime/.
2. Ne diraj assets/style.css i tuđe stranice — tako niko nikome ne kvari rad.
3. Nikad ne stavljaj API ključeve, lozinke ni privatne podatke u kod. Repo je javan.

Korak po korak

Od poziva do live stranice

Prati korake redom. Ako se negde zaglaviš, prvo proveri Debug Diary, pa pitaj u Slack-u.

Prihvati poziv na GitHub repozitorijum

Na mejl ti stiže poziv za repozitorijum n8nlab/aiworkshop. Klikni Accept invitation. Ako nemaš GitHub nalog, napravi ga na github.com/signup istim mejlom.

Preuzmi projekat na svoj računar

Otvori terminal (ili terminal u VS Code / Cursor-u) i pokreni:

git clone https://github.com/n8nlab/aiworkshop.git
cd aiworkshop

Nemaš Git lokalno? Na stranici repozitorijuma pritisni taster . ili otvori Code → Codespaces i radi direktno u browseru.

Napravi svoju granu (branch)

Grana je tvoja lična kopija projekta u kojoj možeš slobodno da eksperimentišeš, bez rizika da pokvariš glavni sajt.

# zameni "marija" svojim imenom
git checkout -b marija/moja-stranica

Pronađi svoj fajl

Tvoja stranica je u folderu ljudi/, npr. ljudi/marija-babic.html. Otvori je u browseru (dupli klik na fajl) da vidiš kako trenutno izgleda. Ne znaš koji je tvoj? Pogledaj stranicu Ljudi.

Zamoli AI agenta da je promeni

Pokreni agenta (Claude Code, GitHub Copilot ili Cursor) u folderu projekta i opiši šta želiš. Budi konkretan i uvek naglasi koji fajl sme da menja. Primer prompta:

Izmeni SAMO fajl ljudi/marija-babic.html.
Upiši moje pravo ime i kratku biografiju: [2–3 rečenice o tebi].
Promeni boje stranice u toplu narandžastu paletu.
Dodaj sekciju "Šta želim da automatizujem" sa 3 ideje iz mog posla.
Dodaj jedan interaktivni element (npr. dugme koje menja citat).
Ne menjaj nijedan drugi fajl.

Osveži stranicu u browseru, pogledaj rezultat i traži ispravke dok nisi zadovoljan. To je ceo trik: opiši → proveri → ispravi.

Sačuvaj promenu (commit)

Commit je snimak tvoje promene sa kratkim opisom. Proveri da si menjao samo svoj fajl, pa sačuvaj:

git status                       # treba da vidiš samo svoj fajl
git add ljudi/marija-babic.html
git commit -m "Marija: nova verzija moje stranice"

Možeš i da kažeš agentu: „Napravi commit sa mojim izmenama" — ali pročitaj šta je uradio.

Pošalji na GitHub (push)

git push -u origin marija/moja-stranica

Terminal će ti ispisati link za Pull Request. Ako te pita za prijavu, koristi svoj GitHub nalog.

Otvori Pull Request

Na GitHub-u klikni Compare & pull request. U naslov upiši svoje ime, a u opis šta si promenio i koji prompt ti je najbolje radio. Vercel će automatski napraviti preview link tvoje verzije sajta.

Showcase — gledamo šta je ko napravio 🎉

Kad su svi PR-ovi spojeni, sajt se objavljuje uživo. Svako ima 2 minuta da pokaže svoju stranicu i kaže jednu stvar koju je naučio. Najbolji prompt ide u Prompt Library, a najzanimljiviji kvar u Debug Diary.

Debug Diary — unapred

Česti problemi i rešenja

„Permission denied" kod push-a

Uzrok: nisi prihvatio poziv ili nisi prijavljen. Rešenje: prihvati poziv na mejlu, pa pokreni gh auth login ili se prijavi kad te Git pita.

Agent je menjao i druge fajlove

Uzrok: prompt nije bio dovoljno jasan. Rešenje: git checkout -- putanja/do/fajla vraća tuđi fajl, a u promptu uvek napiši „menjaj SAMO fajl …".

Stranica izgleda „polomljeno"

Uzrok: obično nezatvoren tag ili pogrešna putanja do CSS-a. Rešenje: otvori DevTools (F12 → Console) i daj agentu tačnu poruku greške.

Conflict kod spajanja

Uzrok: neko je menjao isti fajl. Rešenje: ako si menjao samo svoj fajl, ovo se ne dešava 😉 Ako se ipak desi, pozovi Jovana ili Stefana.
