Dnevnik rada sa AI agentom

Šta smo do sada uradili: od preuzimanja projekta, preko podešavanja Gita, do prvog prompta i izbora pravca za moju stranicu.

Korak po korak

Priprema okruženja

Preuzimanje projekta GOTOVO

Git na početku nije bio instaliran, pa je projekat prvo preuzet kao ZIP arhiva sa GitHub-a. Automatska instalacija Gita (winget i direktno preuzimanje) nije uspela jer je mreža vraćala grešku 504 Gateway Time-out.

Instalacija Gita GOTOVO

Git sam instalirao ručno. Stari terminal ga nije video dok se ne otvori ponovo, jer se PATH učitava samo pri pokretanju terminala.

git --version
git version 2.56.0.windows.4

Kloniranje i moja grana GOTOVO

Projekat je kloniran Gitom i napravljena je moja grana.

git clone https://github.com/n8nlab/aiworkshop.git aiworkshop-git
git checkout -b ivang/moja-stranica

Moj folder GOTOVO

Napravljen je folder ljudi/ivang/ sa stranicom index.html i folderom slike/, po uzoru na stranice drugih polaznika. Folder je kasnije preimenovan u kraće ime ivang, a grana na isti način.

Git ime i mejl GOTOVO

Podešeni su ime i mejl koji idu uz svaki commit (jednom, za ceo računar).

git config --global user.name "ivang"
git config --global user.email "…"

Lokalni pregled stranice GOTOVO

Za pregled u browser panelu pokrenut je mali lokalni server, jer stranica otvorena direktno iz fajla u panelu nije učitala CSS. Na svom računaru je dovoljno dvaput kliknuti na index.html.

python -m http.server 8765
http://localhost:8765/ljudi/ivang/index.html
Prompt 01 · Upoznaj teren

Kako je sajt organizovan

Agent je pročitao README.md, assets/style.css i moju stranicu. U ovom koraku nijedan fajl nije menjan.

🗂️

Struktura

  • Čist HTML + CSS, bez frameworka i bez build koraka
  • index.html: početna (wiki, pojmovnik)
  • zadatak.html: uputstvo za polaznike
  • ljudi/index.html: spisak polaznika
  • ljudi/ime/: lični folder svakog polaznika
🎨

Dizajn i objava

  • Zajednički stil: assets/style.css (ne menja se)
  • Tamna pozadina, limeta naglasak, font Geist
  • assets/main.js: animacije, pretraga, „Kopiraj prompt”
  • Iz mog foldera do CSS-a: ../../assets/style.css
  • Merge u main → GitHub Pages objavi sajt

Izabran pravac: Kontrolna tabla

Izabrano
📊

A — Kontrolna tabla

Stranica kao radni dashboard: traka sa brojkama iz posla, kartice „Šta radim / Šta automatizujem / Šta sam napravio”, hladne boje i mono naslovi.

✍️

B — Lična priča

Minimalistički: velik tipografski uvod, puno praznog prostora, jedna topla boja i vremenska linija od posla preko problema do rešenja sa AI-jem.

🧪

C — Laboratorija

Razigran i eksperimentalan stil: kartice koje se pomeraju, „terminal” koji kuca tekst i mini alat u centru stranice.

Promptovi 02–04

Od šablona do mini sajta

Prompt 02 · Moj identitet GOTOVO

Stranica je redizajnirana u stilu kontrolne table: ime, uloga project manager, kratka biografija, tri reči, traka sa brojkama i tri widgeta. Boja naglaska je hladna plava.

Prompt 03 · Mini alat GOTOVO

Od tri predložene ideje izabran je generator statusnog izveštaja: formular koji slaže nedeljni izveštaj, sa kopiranjem i otvaranjem u mejlu.

Prompt 04 · Mini sajt GOTOVO

Dodate su stranice Kako radim i Projekti sa podstranicom projekta, zajednički meni i zajednički stilovi u stil.css. Sve putanje su relativne.

⏭️

Sledeće: prompt 05 · Provera i objava ČEKA

Pregled svih fajlova, commit na grani ivang/moja-stranica, push na GitHub i otvaranje Pull Request-a.
